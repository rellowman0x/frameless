# Скриншоты

Кидай сюда PNG/JPG-скриншоты браузера — они появятся в секции «Как он выглядит».

Ожидаемые имена файлов (можно добавить свои — просто допиши строку в index.html по образцу):
- start.png    — стартовая страница
- tabs.png     — вкладки
- settings.png — настройки

Если файла нет, секция показывает CSS-плейсхолдер. Меняются табами без перезагрузки.
